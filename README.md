# 串的模式匹配与替换（BF与KMP算法实现）

## 项目简介
本项目为数据结构课程实验代码。使用 C++ 实现了**堆串（Heap String）**的存储结构，并分别应用了 **BF（Brute-Force，暴力匹配）** 算法和 **KMP** 算法来完成特定子串的查找与删除任务。

## 作业任务

### 任务 1：BF 算法匹配与删除
*   **已知条件**：
    *   主串 `S = "abc12abcd123efdk1123"`
    *   子串 `T = "abc"`
    *   存储结构：堆串
*   **要求**：
    *   使用 **BF 方法**找到主串 `S` 中包含的**所有**子串 `T`。
    *   将这些子串从主串中删除。
    *   输出删除后的串 `S`。

### 任务 2：KMP 算法匹配与删除
*   **已知条件**：
    *   主串 `S = "abc12abcd123efdk1123"`
    *   子串 `T = "12"`
    *   存储结构：堆串
*   **要求**：
    *   使用 **KMP 方法**找到主串 `S` 中包含的**所有**子串 `T`。
    *   将这些子串从主串中删除。
    *   输出删除后的串 `S`。

## 文件说明
*   `head.h` : 包含堆串结构体的定义、以及相关基础函数的声明。
*   `String_main.cpp` : 包含 `main` 函数、BF 算法实现、KMP 算法实现（包含求 `next` 数组）、以及串删除功能的实现。

## 编译与运行环境
*   **语言**: C++
*   **建议环境**: Visual Studio / Dev-C++ / Code::Blocks / VS Code (需配置 g++) 等主流 C++ 编译器。

## 如何运行
1. 将 `head.h` 和 `String_main.cpp` 下载至同一文件夹内。
2. 使用 C++ IDE 打开 `String_main.cpp`。
3. 编译并运行，根据控制台提示观察两组实验任务的输出结果。
